# FSD_Project_what2do

The Decision Service preprocessing prototype converts planning and response snapshots into the matching algorithm's typed input. See [its README](decision_service/preprocessing/README.md) for mock examples, local Qwen/Ollama setup, semantic question support, calculated weights, and the local test command. The [algorithm input contract](decision_service/algorithm-input-shape.md) describes the handoff to the matching implementation.
